# TeamOfOne

> Modular open-format library of 790 AI agent skills (1 Master Pipeline Orchestrator + 789 solo-founder specialist `SKILL.md` files) across 15 directories, designed to run a One-Person Company (OPC) through a conflict-free 5-stage connected pipeline.

Repository: https://github.com/silenceminds/TeamOfOne

## Core Architecture & Pipeline Files

- [README.md](https://www.google.com/search?q=https://github.com/silenceminds/TeamOfOne/blob/main/README.md): Overview, department breakdown, and installation instructions for Claude Code, OpenAI Codex, GitHub Copilot, and Google Antigravity.
- [PIPELINE.md](https://www.google.com/search?q=https://github.com/silenceminds/TeamOfOne/blob/main/PIPELINE.md): 5-stage connected pipeline protocol and conflict-free handoff rules shared across all 789 specialists.
- [pipeline-schema.json](https://www.google.com/search?q=https://github.com/silenceminds/TeamOfOne/blob/main/pipeline-schema.json): JSON Schema for shared pipeline state (`locked_goal`, `constraints`, `stage_outputs`, `conflicts`, `schedule`).
- [manifest.json](https://www.google.com/search?q=https://github.com/silenceminds/TeamOfOne/blob/main/manifest.json): Machine-readable index of all 790 skills (`name`, `title`, `department`, `path`).
- [teamofone-orchestrator](https://www.google.com/search?q=https://github.com/silenceminds/TeamOfOne/blob/main/00-orchestrator/teamofone-orchestrator/SKILL.md): Master pipeline router and single tie-breaker for multi-agent OPC execution.

## Pipeline Stages

1. **Stage 1 — Strategy & Lock:** `01-executive-strategy/` and `04-product-design/` lock `goal` and `constraints` (read-only downstream).
2. **Stage 2 — Intelligence & Signals:** `11-scheduled-web-research/` and `12-social-community-monitoring/` gather verified URLs, importance scores (1-5), and leads.
3. **Stage 3 — Execution & Build:** `02-engineering-architecture/`, `03-ai-data-automation/`, `05-marketing-growth/`, `06-sales-revenue/`, `07-operations-management/`, `08-finance-legal/`, `09-customer-success-support/`, `10-people-contractors/`.
4. **Stage 4 — Watchdog & QA Gate:** `14-essential-watchdogs/` audits security, APIs, billing, and compliance risks.
5. **Stage 5 — PDF & Scheduled Connector Delivery:** `13-pdf-leads-delivery/` compiles leads into PDFs, checks for a connected folder (or asks where to save), and exports on schedule.

## Quick Install

Clone the repository and copy any `<department>/<role>/` folder into your agent's skills directory:
- Claude Code: `~/.claude/skills/` or `.claude/skills/`
- OpenAI Codex: `.agents/skills/` or `~/.agents/skills/`
- GitHub Copilot: `.github/skills/`
- Google Antigravity: `.agent/skills/` or `~/.gemini/antigravity/skills/`
